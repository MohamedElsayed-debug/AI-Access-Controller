# AI Access Controller Workflow (n8n)

## 📘 نبذة عن المشروع
هذا الـ Workflow تم تصميمه على منصة **n8n** ليقوم بالتحكم الكامل في الأرقام أو المستخدمين الذين يمكنهم التحدث مع **AI Agent**.  

---

## 🚀 المميزات
- فلترة ذكية للأرقام أو المستخدمين قبل الوصول للـ AI  
- يدعم ربط قواعد البيانات مثل **DataTable**  
- إمكانية السماح أو الرفض حسب حالة المستخدم  
- مناسب للأنظمة الصوتية أو النصية مثل WhatsApp API, Telegram Bots, Webhooks  
- يعمل بشكل أوتوماتيكي بالكامل  
- سهل التعديل والتطوير
